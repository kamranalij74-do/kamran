# ClipForge AI

A local-first, browser-based video editor built with React, Vite, and FFmpeg.wasm.

## Run it

1. Install Node.js 20 or newer.
2. In the project folder run `npm install`.
3. Run `npm run dev`, then open the local URL printed by Vite.
4. Import video, audio, or image files. Drag them from Media onto timeline tracks, or double-click to append them.

Build a static production bundle with `npm run build`; preview it with `npm run preview`.

## Working in this first version

- Import browser-supported video, audio, and image files.
- Add clips to four tracks, move them by dragging, trim clip edges, select, split, and delete.
- Seek and play the timeline; preview image/video clips and audio clips.
- Apply brightness, contrast, saturation, blur, rotation, speed, and volume controls. Color and blur effects are rendered on export.
- Add editable text overlays; save the project and imported media in browser IndexedDB.
- Export a rendered MP4 at 720p or 1080p with FFmpeg.wasm. Video and image clips are arranged by timeline position; blank gaps remain black, and separate audio-track clips are mixed at their timeline positions.
- Create customizable, downloadable PNG thumbnails, and preview voiceovers with free browser text-to-speech voices.
- Listen to microphone captions in browsers that support Web Speech recognition; captions are added as editable clips and can be exported to SRT.

Projects are saved in the current browser profile on this device. Clearing site data removes saved projects. Large media files and the FFmpeg WebAssembly renderer require adequate device memory; exports happen locally and can be slow.

## Browser and AI limitations

- FFmpeg.wasm uses a single-threaded WebAssembly build. Export requires a browser that supports WebAssembly and enough memory. The first export loads the FFmpeg engine from the app's static assets.
- Export burns in clip color effects and includes timeline-positioned audio-track clips. Text overlays, rotation, and speed changes are preview/edit controls and are not currently rendered in the exported picture. Export does not include source audio embedded in video files.
- Video preview uses the browser's media decoders, so supported codecs depend on the browser and operating system.
- English live captions use the browser's Web Speech recognition and microphone permission; this does not transcribe imported video files. Browser support and network requirements vary.
- Browser text-to-speech voices can be previewed, but the browser does not provide a way to export this speech as an audio file.
- Video ideas and scripts are editable local templates, not generated by an AI model. The thumbnail tool is a free canvas designer, not an AI image generator.
- Image background removal, video background removal, and imported-file speech transcription are not implemented. No paid API or AI provider is configured.
